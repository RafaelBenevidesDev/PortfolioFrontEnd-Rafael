## 📌 Sobre o projeto

Este projeto é o meu portfólio pessoal, desenvolvido para apresentar minha identidade como desenvolvedor e destacar minhas habilidades em **front-end** e **back-end**.

A proposta do site é unir:
- visual criativo e imersivo
- animações suaves e interações dinâmicas
- apresentação clara da minha formação e competências
- responsividade para diferentes tamanhos de tela

## 🚀 Como executar o projeto

Como este portfólio é um site estático, você pode abrir o `index.html` diretamente no navegador.

### Opção 1 — Abrir diretamente
1. Baixe ou clone o repositório
2. Abra o arquivo `index.html`
3. Execute no navegador

### Opção 2 — Usar Live Server
Se preferir, você pode abrir o projeto com o **Live Server** no VS Code para facilitar a visualização.
